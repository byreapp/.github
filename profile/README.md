<h3 align="center">Byre</h3>

<p align="center">
  Run PostgreSQL, MySQL and MongoDB side by side on your Mac, and browse any database in Studio.<br>
  No Docker, no Homebrew.
</p>

</p>

---

- **Local servers:** run several versions of PostgreSQL, MySQL and MongoDB at once. Each server has its own port and data folder.
- **Studio:** browse and edit Postgres, MySQL, MariaDB, MongoDB, Redis/Valkey, SQLite and Turso, both local and in the cloud.
- **AI-ready:** connect an AI agent to your local databases.

Releases and issues live in [**byre-releases**](https://github.com/byreapp/byre-releases).
